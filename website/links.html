Open Mapp from anywhere

Any website, message, QR code or AI assistant can link straight into Mapp. One tap opens the app and starts building, opens one of your apps, or joins a shared space.

Link format

Use the web link. It opens Mapp when it is installed and a short page with install instructions when it is not.

https://mapp-site.digitalshift-ee.workers.dev/l/<action>?<parameters>

Inside apps that support custom schemes you can also use mapp://<action>?<parameters>. Encode parameter values with encodeURIComponent.

ActionParametersWhat happens
buildprompt (required, up to 4000 chars)
name (optional)		Opens Mapp and immediately starts building a new app from the prompt.
openapp: app name or idOpens one of the user's apps.
editapp, prompt (optional)Opens the app with the editor and the change typed in. The user reviews it and taps send.
joincode: invite codeJoins a shared space, then offers to build an app on it.
homenoneOpens the Mapp home screen.

Build a link

Let ChatGPT make links

Paste this into ChatGPT (or any assistant). It will answer with links that open Mapp and build what it suggests.

When you suggest an app idea I could use, also give me a Mapp link that builds it:
https://mapp-site.digitalshift-ee.workers.dev/l/build?prompt=<URL-encoded description of the app>
Write the description as a short, complete brief: what it does, the main screens and what data it keeps.

Safety

A build link starts right away, but a request that comes from a link can only create a new app. It cannot read or change the user's other apps, their cloud data, shared spaces or server functions, so a link written by someone else cannot reach personal data. edit links only fill in the request; the user decides to send it. The user always needs to be signed in to their own ChatGPT account, and every build counts against their own plan.
