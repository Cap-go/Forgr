Open Forgr from anywhere

Any website, message, QR code or AI assistant can link straight into Forgr. One tap opens the tool and starts building, opens one of your tools, or joins a shared space.

Link format

Use the web link. It opens Forgr when it is installed and a short page with install instructions when it is not.

https://forgr.ee/l/<action>?<parameters>

Inside tools that support custom schemes you can also use mapp://<action>?<parameters>. Encode parameter values with encodeURIComponent.

ActionParametersWhat happens
buildprompt (required, up to 4000 chars)
name (optional)		Opens Forgr and immediately starts building a new tool from the prompt.
openapp: tool name or idOpens one of the user's tools.
editapp, prompt (optional)Opens the tool with the editor and the change typed in. The user reviews it and taps send.
joincode: invite codeJoins a shared space, then offers to build a tool on it.
homenoneOpens the Forgr home screen.

Examples

https://forgr.ee/l/build?prompt=A%20water%20tracker%20with%20a%20daily%20goal%20and%20reminders
https://forgr.ee/l/build?prompt=Split%20rent%20and%20bills%20between%203%20roommates&name=Roomies
https://forgr.ee/l/open?app=Habits
https://forgr.ee/l/edit?app=Habits&prompt=Add%20a%20weekly%20chart
mapp://build?prompt=A%20compass%20that%20points%20to%20home

Build a link

Let ChatGPT make links

Paste this into ChatGPT (or any assistant). It will answer with links that open Forgr and build what it suggests.

When you suggest a tool idea I could use, also give me a Forgr link that builds it:
https://forgr.ee/l/build?prompt=<URL-encoded description of the tool>
Write the description as a short, complete brief: what it does, the main screens and what data it keeps.

Safety

A build link starts right away, but a request that comes from a link can only create a new app. It cannot read or change the user's other tools, their cloud data, shared spaces or server functions, so a link written by someone else cannot reach personal data. edit links only fill in the request; the user decides to send it. The user always needs to be signed in to their own ChatGPT account, and every build counts against their own plan.
